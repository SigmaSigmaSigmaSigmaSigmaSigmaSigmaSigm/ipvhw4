# ipvhw4

Лабораторна робота 4. Давиденко.

Teachinder: запити до Random User API, пошук, фільтри, сортування, обране та додавання викладачів. Спочатку завантажуються 50 людей, кнопка Next 10 додає ще 10.

Потрібен Node.js 22.12+.

```bash
npm install
npm start
```

Відкрити http://127.0.0.1:3004.

Форма надсилає POST у json-server. Записи зберігаються у db.json, але після оновлення сторінки список знову береться з API.

Тести: `npm test`. check.js можна виконати в консолі браузера після завантаження 50 викладачів. Він додає тестовий запис.
